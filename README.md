# 🎯 Jogo de Adivinhação em Python

Um jogo interativo de console desenvolvido em Python, onde o usuário tenta adivinhar um número secreto sorteado aleatoriamente pelo sistema entre 1 e 20.

---

## 🚀 Funcionalidades

- **Geração Aleatória:** Utiliza o módulo nativo `random` para sortear um número de 1 a 20 a cada execução.
- **Dicas Dinâmicas:** Informa se o chute foi maior ou menor que o número secreto para guiar as próximas tentativas.
- **Detecção de Proximidade:** Alerta com uma mensagem especial (*"O seu chute está pertíssimo!"*) caso o chute esteja a uma distância de apenas 1 unidade do valor correto.
- **Feedback de Vitória:** Exibe mensagem de parabenização assim que o usuário acerta o número.

---

## 🛠️ Tecnologias Utilizadas

- **Python 3.x**
- Módulo nativo `random`
